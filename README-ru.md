## Возможности в связке с [tgbridge-client](https://github.com/Durhol/tgbridge-client)

- **🖼️ Миниатюры фото прямо в чате**: фотографии из Telegram отображаются миниатюрными превью внутри строк чата Minecraft без задержек и без внешних запросов к Telegram CDN.
- **🔍 Полноэкранный просмотр изображений**: клик по миниатюре открывает удобное окно просмотра фото с догрузкой оригинального качества.
- **📋 Отправка фото по Ctrl + V**: вставка скриншота из буфера обмена прямо в игровой чат и отправка в группу/топик Telegram.
- **🎙️ Голосовые сообщения**: запись микрофона прямо из чата игры и прослушивание входящих голосовых из Telegram.
- **💬 Удобная система ответов (Reply)**: цитирование и ответы на конкретные сообщения из Telegram прямо из игры.
- **🎨 Кастомный пиксель-арт интерфейс**: аккуратные пиксельные иконки вместо смайликов и эмодзи.

## Фичи

- Поддерживает Fabric, (Neo)Forge и Paper
- Поддерживает большинство модов и плагинов
- Работает с топиками Telegram (бот будет работать только в указанном топике)
- Каждая функция может быть настроена или отключена
- Многое другое! Полный список функций на странице https://tgbridge.vanutp.dev/ru/features
